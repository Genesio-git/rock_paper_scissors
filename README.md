# Rock Paper Scissors ✂️

Jogo de Pedra, Papel e Tesoura desenvolvido com JavaScript.

## 🎮 Sobre o projeto

O jogador digita sua escolha via `prompt` do navegador. O computador faz uma escolha aleatória e o resultado de cada rodada é exibido no console. O jogo roda por 5 rodadas e ao final exibe o placar.

## 🛠️ Tecnologias utilizadas

- JavaScript
- HTML5

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador
2. Abra o console do navegador (F12)
3. Digite sua escolha quando solicitado: `pedra`, `papel` ou `tesoura`
